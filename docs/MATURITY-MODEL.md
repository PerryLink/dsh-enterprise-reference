# Maturity model

| Level | Name | Characteristics |
|---|---|---|
| L1 | Ad hoc | individual installs, shared keys, no audit |
| L2 | Defined | SSO, RBAC, allowlists, basic logs |
| L3 | Managed | central control plane, canary upgrades, compatibility gate, SIEM |
| L4 | Optimized | automated evidence, continuous control testing, cost/quality SLOs |

Most enterprises should target **L3** before scaling beyond one department.
